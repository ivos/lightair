# Generate XSD

**Generate XSD from database to enable writing dataset files**\
Use the [LightAir Maven plugin](http://lightairmp.sourceforge.net/)
(or call
[LightAirApi.generateXsd](https://lightair.sourceforge.net/apidocs/net/sf/lightair/LightAirApi.html#generateXsd()))
to generate XSD files from the database
that will help you write the XML dataset files.
