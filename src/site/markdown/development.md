# Development

Any help with the development of Light Air is very welcome.
Please contact me if you have any additions.
You can also create a ticket on the project's GitHub repo.

## Git repo

Available at https://github.com/ivos/lightair.

To clone the repo (read-only):

```shell
git clone https://github.com/ivos/lightair.git
cd lightair/
mvn install
```
